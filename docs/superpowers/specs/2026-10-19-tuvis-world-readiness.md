## 3. 云端交付前置条件

- 静态阶段先交付展示页所需素材、内容和版式参考；互动阶段交付准备完成的运行素材、manifest、摆放/遮挡预览及场景数据。
- 文件通过目标仓库提交或经校验的附件提供，不能以本机绝对路径作为云端可访问证据。
- 素材清单包括相对路径、用途、尺寸、透明通道、来源、完整生成提示词和文件校验；每个 manifest 引用都能在解包后定位。
- 归档收录实际采用的需求、素材与数据；预览能让识图 Agent 对照实现。
- 发布资源通过站点读取，兼容 /tuvis-website/ base。附件和仓库均不携带 node_modules、密钥或缓存。

当前 Git 仅追踪书面资料及斜俯视方向图的一部分，其他多数素材尚未进入目标仓库；尚无最终交接 ZIP。交接时须重新核对目标分支与实际文件。

## 4. 开发环境准备

工程采用配套需求书中的 React / TypeScript / Vite / CSS-SVG 方案，已有依赖覆盖所需能力。

已核实的本机与仓库情况：
- Node v26.8.1、npm 11.19.0；node_modules 不存在。
- package.json 固定 pnpm@11.13.0；在仓库执行 pnpm --version 报 broken release / @pnpm/exe 缺少二进制。
- CI 使用 Node 22，并按 packageManager 安装 pnpm，再执行 frozen install、测试与构建。
- 开发准备需统一至需求书规定的 Node 22，验证可安装的 pnpm 版本并同步 packageManager、锁文件与 CI。

这是本机观察，云端需重新验证。尚未安装依赖、运行产品构建、创建 world 页面或发布站点。访客只使用部署后的网页。
