# 一、Tuvis 吉祥物设计定稿

# Tuvis · 少年兔科技管家

Core character definition

聪明、机灵、略带顽皮的少年兔，拥有自然的动物外形、轻量科技装备和可靠的技术助手气质。

角色性格

机灵、自信、可靠

整体比例

大头三头身

核心装备

透明蓝色 HUD

品牌标志

胡萝卜能源徽章

## 1. 外形规范

| 部位     | 定稿设计                            |
| ------ | ------------------------------- |
| 物种与年龄感 | 灰白色拟人兔，具有男性少年气质，不刻意强调成熟男性特征     |
| 头部     | 偏大的椭圆形兔脸，脸颊柔和但不过分鼓胀，下巴自然收窄      |
| 耳朵     | 两只较长的兔耳，整体向上，其中一只轻微倾斜，形成固定的角色特征 |
| 眼睛     | 自然深棕色生物眼，有真实高光，不发光、不机械化         |
| 口鼻     | 柔和的白色口鼻区域、粉色小鼻子                 |
| 表情     | 轻微自信的微笑，嘴角略微上扬，不坏笑、不面无表情        |
| 尾巴     | 一个小型自然灰白绒球，主要在侧面和背面视图中展示        |
| 毛发     | 集中在头、耳朵、口鼻及尾巴，手腕和脚踝连接处允许露出极少量短毛 |
| 颈部     | 贴合身体的枪灰色科技领口，不出现毛绒领圈            |

这里有一个关键的比例定义：三头身以耳朵以外的角色身体高度计算。

头部占比大，但身体不能因此被压缩成一个圆球。肩部适度宽于腰部，四肢短而有力，胯部和腿部保留自然的兔类结构。目标是少年感，而不是幼儿玩偶感。

## 2. HUD 眼镜规范

它是 Tuvis 最重要的识别元素之一，不能在后续设计中随意替换。

保留横向圆角长条形的一体式镜片、轻薄白色边框、微弧下缘和右侧小型青蓝传感器。

镜片必须足够透明，让棕色眼睛清晰可见。只保留少量极淡的青蓝色界面线条，不在镜片上添加密集的文字、数字和发光图案。

HUD 的作用是暗示信息处理、监控与智能辅助，而不是把兔子变成戴着机器人面罩的角色。

## 3. 身体与装备规范

底层：深灰色贴身科技服

采用哑光技术织物，包裹躯干和四肢。腰侧、腋下、肘部及部分大腿保留柔性材料，让身体自然、有运动感。

外层：轻量模块化装甲

仅在胸口、肩部、前臂、膝盖和小腿设置银白色防护板。板块圆润、薄而有结构感，沿着身体轮廓包覆，不使用厚重的全身重甲。

手套与战靴：保留兔类特征

手套拥有灵活的手指、圆润的指尖与略带肉爪感的掌部。战靴前端自然宽圆，不能变成过于笨重的机械脚。

整体装甲必须遵循同一套曲线语言，少用尖角和复杂机械接缝。胸甲可以稍微突出，但不能形成庞大的球形胸腔；腰部和大腿不能因为盔甲分层而显得臃肿。

暖铜色不再作为主要装饰色。保留枪灰关节和少量青蓝细节就足够了。

这套设计保留了未来科技助手的感觉，但不复刻任何特定超级英雄的装甲轮廓、圆形反应堆或标志性色彩组合。

# 二、胡萝卜能源徽章：冻结结构，变化只发生在主体

这是 Tuvis 最重要的产品符号之一。我建议将它独立定义为 Tuvis Status Core，以后不论立绘、托盘图标还是软件状态徽章，都遵循同一套基本轮廓。

设计结构示意 · 非最终图形资产

### 固定结构

两片叶子

暗青绿色珐琅或宝石材质，固定配色，完全不发光。

金属包边

银白色、线条细致、嵌入胸甲，体现精密装备感。

主体轮廓

顶部宽、下端收尖，具有清晰的胡萝卜辨识度。

状态灯体

半透明玻璃或能源晶体质感，颜色变化只发生在这里。

## 三种状态外观

绿色 · 默认主视觉

Default

表现正常、可靠、随时可用的品牌气质。用于第一张主视觉立绘。

黄色 · 活跃状态变体

同一角色、同一构图、同一材质，仅主体变为琥珀黄色。可用于表现活动、处理中的视觉情境。

红色 · 需要关注的变体

表达需要关注或介入的视觉提示。但这属于吉祥物品牌视觉语义，不意味着自动修改 Tuvis 当前软件的状态映射。

这里需要严格遵守一条规则：叶片、金属包边、镜片、兔毛和装甲都不跟着状态变色。 三个版本只有胡萝卜主体颜色发生变化。黄色和红色版本必须沿用绿色母版的构图和比例，不能重新生成出不同的角色。

此外，静态图片中的绿色、黄色、红色只是视觉表达。软件当前已有的状态含义继续独立维护，避免宣传物料的设计选择反过来改变产品行为。

# 四、完整品牌资产清单

我建议把交付内容分成两个阶段。第一阶段建立角色与图标的标准母版；第二阶段再扩展宣传、表情和动态资产。

## 第一阶段：必须建立的核心资产

01 · 全身主视觉立绘

核心资产

少年兔的完整 3D 角色渲染，默认使用绿色胡萝卜核心。建议竖版构图、纯白背景、正面略带三分之四角度的站姿，展示完整耳朵、四肢、装甲和尾巴。

交付：高分辨率 PNG 白底版、透明背景版，以及适合 README 的裁切版本。

02 · 胸灯红黄绿三态立绘

同一角色、同一姿态和构图，分别导出绿色、黄色、红色版本。仅改变胡萝卜主体发光颜色。

交付：三张可直接比较的独立图像，以及状态颜色规范。

03 · 兔头品牌标志

将长耳、脸部轮廓、棕色眼睛和简化 HUD 抽象成一枚独立图形。删除毛发细丝、金属反射和密集数据界面。

交付：可编辑 SVG、透明 PNG、黑白单色版。

04 · 软件应用图标

以兔头 HUD 为主体，不强行塞进全身装甲和胸灯。建议优先设计深枪灰背景版本，辅以一个浅色背景版本。

交付：SVG 母版、1024 × 1024 PNG，以及根据正式发行平台导出的图标格式。

05 · 胡萝卜状态图标

只显示简化后的胡萝卜徽章，固定暗青绿叶片与边框，主体使用三种状态颜色。

交付：红、黄、绿三态 SVG，及 16、20、24、32、48 像素等常用尺寸的导出版本。

06 · 品牌使用规范

汇总角色比例、标准配色、材质、HUD、胡萝卜核心、图标缩放规则和禁止事项，作为未来所有视觉资产的统一参考。

交付：一份精简的品牌规范文档，以及可编辑的矢量母版。

## 第二阶段：建议补齐的扩展资产

| 资产                     | 作用                  |
| ---------------------- | ------------------- |
| 角色正面、侧面、背面设定图          | 让未来的插画、3D 模型和动作保持一致 |
| 头部与 HUD 特写             | 用于官网介绍科技装备与角色细节     |
| 中性、思考、微笑、关注等表情表        | 用于 README、通知和产品帮助页面 |

| 图标安全区与最小尺寸规范           | 避免未来不同开发者随意拉伸或重绘    |

这一阶段可以后续逐步完成，不需要在首次制作中全部投入。

# 五、图标需要特别遵守的技术规范

这是我认为最容易被忽略、但对软件项目最重要的部分。

## 应用图标与状态图标必须分工

应用图标：兔头 + HUD

用于应用启动器、桌面快捷方式、网站头像等。角色本体是识别中心，不绑定某一种运行状态。大尺寸可以保留眼睛，缩小之后优先保留耳朵、脸和横向镜片。

托盘状态图标：胡萝卜核心

用于实时提醒或状态展示。胡萝卜主体变色，叶片不变。小于 32 像素时，去掉内部高光、渐变层和细小轮廓，只保留容易辨认的整体形状。

我不建议在 16 × 16 像素图标里保留逼真的金属反射和复杂玻璃效果。矢量图形的基础识别度必须先成立，材质细节只能作为大尺寸增强。

同样，在实际软件里，状态不能只靠颜色区别。对于红色状态，还应配合具体的会话说明、图标或标签，避免用户无法区分待输入、待审批和错误。

# 六、需要明确的禁止事项

为避免未来再次偏离，我建议将以下内容正式纳入设计规范。

禁止重新变成重型机甲

不做全身厚金属包覆、过度膨胀的胸甲、笨重的球形肩甲和密集的机械关节。

禁止使用毛发作为装饰配件

不加毛绒领圈、蓬松护腕和独立毛绒装饰。只保留自然身体上的毛发。

禁止复杂化胡萝卜轮廓

不使用三片发光叶子、机械天线叶冠和密集叶脉，不让金属、叶片和灯体分别使用不同的发光机制。

禁止削弱自然兔子特征

不让眼睛变成发光镜头，不让 HUD 完全遮住眼睛，也不把兔耳改成机械天线。

禁止依靠复杂细节制造科技感

不铺满全身的数据文字、灯条、机械缝隙和装饰线。所有细节都必须服务于识别度、功能感或整体结构。

# 七、最终制作顺序

为了减少返工，我建议严格按照以下顺序推进。

1. 确定三维角色母版

   先做好大头三头身比例、自然兔脸、HUD、轻量装甲和胡萝卜核心。默认绿色，白色背景，正面略带三分之四角度。
2. 锁定角色结构与胡萝卜徽章

   确认头部、躯干、四肢的宽度关系，以及胸灯轮廓、双叶和银色包边。不在后续版本随意改变。
3. 制作黄灯、红灯同构版本

   仅改变胡萝卜主体颜色，其他造型和细节保持一致。
4. 独立绘制矢量兔头与胡萝卜图标

   不直接将完整 3D 图像缩小或自动描摹成 SVG。应该依据已经确认的角色设计，重新建立简洁、可编辑的矢量轮廓。
5. 输出正式品牌资产包

   整理透明背景立绘、应用图标、三态托盘图标、单色版和设计规范，确保各类文件可以直接用于软件开发与宣传。

我的最终判断是：Tuvis 应该先成为一个有鲜明个性的角色，再成为一个简洁的品牌符号。 立绘靠表情、材质和整体造型体现灵魂；兔头图标负责让人认出 Tuvis；胡萝卜核心负责建立独特的品牌联系，并在合适的场景中表达状态。

这套设计规范已经可以作为后续出图、制作 SVG 以及开发软件图标的统一依据。下一步最值得先完成的资产是绿色主视觉立绘，因为它会成为所有其他图形的造型来源。
