# 图标配色规格（v3 最终定稿，2026-10-10）

形状基准：candidate-A-clean / candidate-C-light（两图形状一致，仅区域配色不同）。
目镜 = 一整块渐变玻璃（顶条位置 + 镜片 + 鼻托连通域），渐变铺满整块，**不随底牌**；无边框、无顶条、无指示灯（相关候选均已被否，见同目录归档）。

| 区域 | 深色版 | 浅色版 | 规则 |
|---|---|---|---|
| 圆角底牌 | `#2C3347` | `#FEFEFE` | 黑白对照互换 |
| 兔头 + 双耳 | `#F7FAFD` | `#2C3347` | 黑白对照互换（藏蓝全站唯一值） |
| 目镜（一整块玻璃） | 蓝渐变三段 `#0980D0→#3EA1D3→#61D2E7`（左深右亮） | 白→浅灰 `#FEFEFE→#D5D9DE`（左白右灰） | 渐变只放目镜上，不随底牌 |
| 嘴 | `#2C3347` | `#FEFEFE` | 跟随底牌色（负形） |

换算规则：任意一版 → 另一版 = 底牌↔头互换，嘴随底牌，目镜渐变保留各自定义。
