# TUVIS WORLD DESIGN

> 版本：v0.2  
> 状态：**第一期设计草案（不改网页代码）**  
> 定位：**轻互动探索型角色专区**

## 1. 项目目标
Tuvis World 第一期开一个独立的角色专区，用来介绍兔维斯、他的常用装备、他的发明工坊与回路城，并放入第一批故事内容。目标不是做完整互动游戏，而是做一个**可探索的原创角色世界入口**。

## 2. 已确认方向（APPROVED）
- **角色定位**：Tuvis / 兔维斯是**独立原创角色 IP**，不是只依附于软件的吉祥物。
- **基调**：**科技轻喜剧**。兔维斯聪明、机智、有爱心，不轻易主动挑衅，但遇到不公或麻烦时会用巧思化解。
- **世界模型**：**混合型智慧文明**。回路城中生活着进化动物、智能机器人、原创类人生物等不同居民。
- **页面形态**：**轻互动探索型**。点击装备、工坊物件与地点，可以展开趣味设定。
- **第一期故事展示方式**：**B** —— 1 篇完整小故事书 + 2 张故事预告卡。
- **视觉方向**：采用**明亮、色彩鲜明、科技感十足的 3D 动画风**，与已确认的兔维斯 3D 主图保持一致。

## 3. 角色核心
### 兔维斯（Tuvis）
- 灰白长耳兔，青蓝透明 HUD 护目镜
- 深石墨色内甲，银白局部装甲
- 胸口嵌入式胡萝卜能源核心，双片固定暗青绿叶片
- 性格关键词：聪明、机灵、可靠、略带俏皮
- 世界身份：年轻发明家、问题解决者、工坊主人

## 4. 装备家族（正式修正版）
> 本次统一修正上一版下载包中的装备命名，并按这版冻结为第一期对外写法。

### 4.1 Diff Radar｜差异探测雷达
- **识别色**：红色
- **定位**：扫描、审查、发现异常、追踪线索
- **轮廓**：弧形扫描阵列，中央透镜，左右展开传感翼
- **趣味描述**：最擅长看见别人忽略的小细节，有时也会放大兔维斯自己忽略的问题。

### 4.2 Bug Buster｜Bug 清除脉冲炮
- **识别色**：橙色
- **定位**：处理异常、Debug、紧急介入
- **轮廓**：短粗大型脉冲炮，宽大炮口与能量环
- **趣味描述**：看上去最有气势，但兔维斯并不总是用它解决问题。

### 4.3 Code Weaver｜代码编织终端
- **识别色**：蓝色
- **定位**：编码、构建、生成、发明
- **轮廓**：小型高科技终端，适合手持操作与构建逻辑结构
- **趣味描述**：兔维斯最常用的日常工具，很多新点子都从这里开始。

### 4.4 Merge Prism｜代码融合棱镜
- **识别色**：绿色
- **定位**：合并、补丁、整合、连接
- **轮廓**：小型多面体数据棱镜，强调汇流与融合
- **趣味描述**：适合修复分离的东西，也很适合象征合作与和解。

## 5. 第一期开站内容
### 模块 A｜认识兔维斯
展示 3D 主图、角色一句话介绍、3 个性格标签，以及 HUD、胡萝卜核心等标志性特征。

### 模块 B｜装备图鉴
展示四件装备卡片。点击后展开名称、识别色、功能说明和一句趣味设定。

### 模块 C｜探索工坊与回路城
- **工坊热点（3 个）**：装备架、实验工作台、休息角落
- **城市地点（2–3 个）**：发明工坊街、空中商业街、未完成品仓库（可作为候选）

### 模块 D｜故事档案
- 主故事：**《完美的一天，差一点》**（完整故事书）
- 预告故事：**《谁动了我的零件？》**、**《最厉害的武器》**（封面 + 一句话简介）

## 6. 第一批故事方向
### 6.1 《完美的一天，差一点》
兔维斯设计了一套自动化日程系统，想让一天完美运转，却因为一个小小的基础错误引发连锁混乱。最后他冷静下来，用更简单的办法让一切恢复正常。

### 6.2 《谁动了我的零件？》
工坊零件接连消失。兔维斯启动 Diff Radar 追查，最后发现“犯人”其实只是想修好自己住所的小机器人。兔维斯决定帮它把事情做完。

### 6.3 《最厉害的武器》
商业街出现一台失控的大型清洁机器。兔维斯搬出 Bug Buster，却发现真正有效的并不是火力，而是重新理解并修改机器的任务规则。
